Dieses Werkzeug greift auf dieselbe Firebase-Datenbank wie das Terminal zu. Aus Sicherheitsgründen (Firestore-Regeln) ist dafür zwingend eine echte, authentifizierte Admin-Session nötig — melde dich mit deinem bestehenden Agenten-Account an, der in Firestore das Feld isAdmin: true gesetzt hat.

PASSWORT-VERWALTUNG

Das Firebase-Client-SDK kann aus dem Browser heraus grundsätzlich nur das Passwort des gerade eingeloggten Accounts ändern — nicht das fremder Nutzer. Dieser Button ruft daher die Cloud Function adminResetPassword auf (siehe mitgelieferte functions/index.js). Solange diese nicht deployed ist, erscheint hier ein Fehler statt eines stillen Fehlschlags.
